Timer sencillo en C

2026-09-02
  • #C
  • #Timer

Este simple programa te permitirá medir el tiempo de ejecución de tus programas. Para el programa necesitaremos las siguientes librerías:

  • stdio
  • stdlib
  • unistd
  • sys/wait
  • sys/time

Necesitaremos obtener el nombre del programa (el cual queremos medir el tiempo de ejecución), así como sus argumentos. Para ello tomaremos los datos a través de los argumentos de la función main. Además, haremos una simple validación:

int main(int argc, char *argv[]) {
  if (argc < 2) {
    printf("Usage: time program [args...]\n");
    return 0;
  }
...
}

Para medir el tiempo, utilizaremos gettimeofday, que recibe como argumentos un puntero a una estructura timeval (que registra el tiempo), y otro puntero, que asignaremos a NULL (no nos interesa este resultado):

int main(int argc, char *argv[]) {
...
  struct timeval stop, start;
  gettimeofday(&start, NULL); // Inicializamos el timer (tomamos el tiempo inicial)
...
}

Necesitamos generar un proceso nuevo, el cual se encargará de ejecutar el programa que queremos probar. Para eso utilizaremos fork, la cual crea un nuevo proceso, hijo del actual proceso.

Fork devuelve 0 en el proceso hijo, un número mayor a 0 en el proceso padre (el PID) y -1 en caso de error. Utilizaremos el valor devuelto por fork para evaluar diferentes enunciados según sea el proceso:

int main(int argc, char *argv[]) {
...
  int rc = fork();
    if (rc == -1) {         // Error
      ...
    } else if (rc == 0) {   // Proceso hijo
      ...
    } else {                // Proceso padre
      ...
    }
...
}

En caso de error, finalizaremos el programa:

  if (rc < 0) {
    fprintf(stderr, "fork failed\n");
    exit(1);
  }

En la creación del nuevo proceso hijo, fork copia los valores de las variables de su proceso padre, esto incluye los parámetros de la función main, estos datos nos serán de ayuda para ejecutar nuestro programa.

Para ejecutar nuestro programa, utilizaremos la función execv, que toma como primer argumento la ruta de acceso a nuestro programa (por ejemplo: ./mi-programa), y como segundo argumento un arreglo, que contiene la ruta de acceso y la lista de argumentos del programa. Cada término ha de ser un string.

Para definir este arreglo, iteraremos desde el segundo parámetro de argv hasta el final. Haciendo copias de los punteros a los string. Por último, agregaremos NULL, necesario según las especificaciones de execv:

  else if (rc == 0) {
    int i;
    char *myargs[argc];

    for (i = 0; i < argc - 1; i++)
      myargs[i] = argv[i+1];
      
    myargs[i] = NULL;

    execv(myargs[0], myargs);  
    exit(1);
  }

Execv finaliza la ejecución del programa por sí mismo, agregamos exit en caso de que ocurra un error en execv, así el programa pueda finalizar.

Por último, en nuestro proceso padre, solo nos queda esperar a que el proceso hijo finalice, utilizaremos la función wait, a la cual pasaremos NULL (significa que esperamos a cualquier proceso):

  else {
    wait(NULL);
  }

gettimeofday registra los segundos y microsegundos pasados desde un determinado tiempo en particular (es el mismo para toda invocación de la función), por lo tanto, para calcular el tiempo pasado desde que empezamos a ejecutar el programa hasta finalizar, debemos calcular la diferencia.

La estructura timeval contiene dos campos, tv_sec y tv_usec, para obtener un resultado coherente, debemos transformar las unidades a una unidad en común, en este caso usaré milisegundos.

Por último, mostramos el resultado en consola utilizando printf:

int main(int argc, char *argv[]) {
  ...
  gettimeofday(&stop, NULL);
  printf("time: %ldms\n", ((stop.tv_sec - start.tv_sec) * 1000 + (stop.tv_usec - start.tv_usec) / 1000));
    
  return 0;
}

Programa completo:

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <sys/time.h>

int main(int argc, char *argv[]) {
  if (argc < 2) {
    printf("Usage: time program args...\n");
    return 0;
  }

  struct timeval stop, start;
  gettimeofday(&start, NULL);

  int rc = fork();
  if (rc < 0) {
    fprintf(stderr, "fork failed\n");
    exit(1);
  } else if (rc == 0) {
    int i;
    char *myargs[argc];

    for (i = 0; i < argc - 1; i++)
    myargs[i] = argv[i+1];

    myargs[i] = NULL;

    execv(myargs[0], myargs);  
    exit(1);
  } else {
    wait(NULL);
  }

  gettimeofday(&stop, NULL);
  printf("time: %ldms\n", ((stop.tv_sec - start.tv_sec) * 1000 + (stop.tv_usec - start.tv_usec) / 1000));

  return 0;
}

Compilamos y ejecutamos un ejemplo:

$ gcc timer.c -o timer
$ ./timer ./insertionsort test
time: 78ms
